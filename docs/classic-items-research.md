# 经典「零和博弈」装备与投资策略资料

本文件记录 `dist/classic-items.js` 的数据依据。它是旧赛季规则的可执行子集，不是宣称完成了原游戏的全部内容。版本基线为 4.7「入画奇航」大改前的「零和博弈」：保留可以追溯的 3.8 装备加强；策略使用 2026-08-30 整理的旧赛季资料快照，未将无法确定引入版本的新数值混入。

## 已覆盖的数据

- 8 种常规简易装备、36 种普通进阶装备，完整无序合成表；不再把其他配方统一合成为自制「复合式战斗模块」。
- 33 项有明确触发时机和数值、可被本作战斗及经济系统实现的旧赛季投资策略。
- 基础装备恢复为前后台强度、百分比生命/速度、幸运一击率、击破效率与初始能量。不是过去自制的固定攻击/固定生命加成。
- 装备 ID 保留旧存档兼容；显示名称、合成与效果按旧赛季资料更新。例如 `blade` 现在是「碎星斩舰刀」，`garden` 是「生命之环」，`hybrid` 是「武器大师」。

目前未纳入红蓝钻、财富宝钻与星徽配方、特权装备、专家改件、召唤物专属装备，以及所有剩余策略。对有对应前置机制的策略应先完成该机制再加入随机池，不能只显示原版描述却不执行效果。

## OCR 和版本冲突的处理

- 资料快照把「步步生花」误写成“前台加 70% 生命”。实际是前台角色**当前生命超过上限 70%**时获得额外伤害；已按条件效果处理。
- 「进化手册」「反卫星狙击」「以牙还牙」在 OCR 中被简写，采用完整装备名「战场进化手册」「反卫星狙击枪」「以牙还牙甲」。
- 当前 BWIKI 策略页面与 2026-08-30 快照存在若干差异，但具体引入版本尚未确认：延迟收益 100→60 行动值，基层贡献 3%/2%→6%/4%，三三三强度 20%→25%，中产阶级新增立即 3 金币，概率事件 45%→50%。模块保留可追溯快照的前者，未收录概率事件；不把这些不明版本差异伪装为已证实的原版还原。
- BWIKI 当前部分装备属性没有 OCR 表中出现的击破/治疗附加数值。模块以装备单项表当前列出的基础属性为准，不凭配方原料自行推导附加属性；普通进阶装备本来就不等于两件材料属性简单相加。

## 引擎对接约定

装备百分比字段均为小数：`.20` 表示 20%。`startEnergy` 是固定能量点数。字段为 `frontPower`、`backPower`、`hpPct`、`speedPct`、`damageAmp`、`damageReduction`、`crit`、`startEnergy`、`breakEfficiency`、`breakEffect`、`shieldAmp`、`healAmp`。`passive` 标识明确的战斗触发器；`unique` 和 `exclusiveSlots` 是必须执行的装备限制。

幸运一击不能只改面板：它应影响可触发的伤害判定。前台强度仅作用于前台输出/技能，后台强度作用于后台赋能。护盾反伤应保留“无法击杀”；削韧效率和击破特攻是不同属性；行动值回能需要按经过的时间结算，不能改为每回合固定回能。

「以牙还牙甲」「光能盾牌」有防御力比例护盾；原版角色属性/防御伤害公式未全部重建前，应在游戏说明中明确二维适配方式。原版波次、行动值惩罚、召唤物和状态持续时机也不能被宣称为完全等同。

策略由 `effect` 提供经济参数、由 `effect.battle` 提供战斗参数。即时奖励只在选择策略时触发一次；加载存档时不要再次发放。`nodeGoldLimit` 只计选择后的新节点，`planes` 表示出现位面，`purchaseXp` 每个费用档位只奖励第一次购买。出售或迁移旧存档不得重复领取奖励。
