# 经典模式与节点流程核对（网站 v6）

目标仍是 4.7 改版前的「零和博弈」。资料核对时间：2026-11-14。这里把能够核实的机制和网页数值适配分开记录，未读取或声称取得原版服务器实现。

## 核实的结构

- 标准博弈与超频博弈是旧版的两个模式。标准模式用于晋升；超频更短，不能晋升。参考 [旧赛季页面](https://honkai-star-rail.fandom.com/wiki/Currency_Wars%3A_Zero-Sum_Game)、[BWIKI 货币战争](https://wiki.biligame.com/sr/货币战争)。网页提供两者供直接选择，不设置原版账号解锁门槛，也不发放原作账号奖励。
- 三个位面，每个位面有战斗、奖励、补给、遭遇、首领等节点。投资策略阶段是在战斗前选择强化，并非领取后直接跳过战斗。[4.0 版教学目录](https://hsr.gachabase.net/tutorials/currency-wars/release/4.0.0/14365601?lang=en)、[位面与节点教学](https://hsr.gachabase.net/tutorials/currency-wars/100036/planes-and-nodes/beta?lang=chs)、[3.7 开门自由贸易攻略](https://www.miyoushe.com/zzz/article/70549693)。教学页面的 beta 链接仅用来交叉核对与旧版资料一致的节点名称，不据此引入新赛季玩法。
- 标准第一位面为九节点，后两个位面为七节点。[2025-11-14 的实际游玩记录](https://m.hupu.com/bbs/635729773.html)明确列出 1-3 投资后战斗、1-5 补给、1-7 遭遇、1-9 首领、2-3 补给、2-5 遭遇、2-7 首领。用户提供的 3-7 原版截图也呈现七节点路线。网页采用 9+7+7，共 23 节点。
- 标准路线：第一位面「奖励、奖励、投资战斗、战斗、补给、战斗、遭遇、奖励、首领」，后两位面「战斗、投资战斗、补给、战斗、遭遇、奖励、首领」。第一位面开头奖励安排依据公开实机开局流程整理；这不是客户端配置文件的直接提取。
- 超频的确定规则是：每个位面较少节点、每节点更多经验与金币、**不再获得利息**。[4.2.0 已发布版本教学](https://hsr.gachabase.net/tutorials/currency-wars/100060/overclock-gambit-rules/release/4.2.0/14809204)。当前尚未取得可交叉验证的完整历史超频节点表，网页明确采用每位面「投资战斗、补给、遭遇、首领」的四节点压缩流程，共 12 节点；不将这个数量冒充原版原始配置。
- 补给是角色和装备组成的礼包选择，选择后无战斗。遭遇提供不同难度，较难分支有更高品质奖励。奖励节点是低难度战斗并掉落晶矿。三者已经是不同状态和执行路径，而不是换标题的普通战斗。
- 原版失败不提供连败经济；仅连胜有奖励。旧网页将负连胜值也转为额外收入，现已在新标准/超频模式移除。保留旧 12 关存档原经济，以免进行中的旧局被重平衡。
- 原版整局最终以小队生命是否仍大于零判胜，最终首领没有完胜不等于整局自动判负；生命 >=70 / >=40 / >0 对应标准晋升 +3 / +2 / +1。新模式已据此结算，失败扣生命参考实际未完成的敌方生命比例。网页显示本局晋升评价，不冒充原作账号职级。

## 已实际接入的流程

新局：模式和难度 → 投资环境三选一（一次刷新）→ 节点筹备 → 投资选卡 / 补给礼包 / 遭遇难度 → 战斗或补给后继续 → 自动战后结算 → 下一节点 → 第三位面最终结算。

- 节点选择和奖励写入存档。重复确认不能重复获得资源；补给不会凭空产生一条战斗记录。
- 每次进入节点刷新商店（锁店除外），结算节点收益、经验和跨节点成长。
- 「人身意外险」会在每个首领前实际插入补给选择，选完仍要进行该首领战斗；「共同决策」「战略大师」会在指定节点额外选策略；「战争边疆」改第三位面普通战斗为遭遇；「过剩经费」给双份装备；品质环境限制真实策略池，刷新也保留品质要求。
- 装备、羁绊、环境收益都使用实际背包或晶矿。资金可通过角色出售回笼，已装备物品返回仓库；出售价格统一通过 `getSellPrice` 提供给按钮与执行逻辑，当前是费用乘角色所含一星份数。没有找到可核验的旧版完整折损表，未擅自增加折损。
- 旧 v1/v2/v3 存档继续原 12 关路线，不把正在进行的对局突然切换为 23 节点。新局带 `flow.mode`；成长校验上限随路线长度变化，修复了原先第 13 节点以后会被视为坏档的问题。

## 明确的模拟适配

- 敌方仍使用当前网页的三类位面敌人和逐回合战斗实现；普通、奖励、遭遇、首领各自使用不同参数，三档挑战难度真实改变敌方生命和攻击。难度名为「入门 / 进阶 / 挑战」，没有冒用 A8 等原版职级。
- 新标准局基础收入 5、胜利收入 1、利息每 10 金币 1（通常上限 5）；连胜奖励按每两胜增加 1、上限 3。确切完整原版收支表未取得，这些基础数值属于模拟调节。超频初始 36 金币、每新节点额外 12 金币/6 经验，也属于明示的调节值。
- 4→5 到 9→10 的经验门槛为 10/20/32/48/64/84。9→10 的 84 可从用户实机截图核实，其他完整旧值未核实，因此没有标注「原版经验表」。标准每新节点 2 经验。
- 补给随机卡池、武装箱数量、遭遇三个难度与奖励组合、奖励节点晶矿数量均为可玩的模拟奖池，不声称还原服务器掉率。红蓝钻进入第二、三位面补给，选择后以晶矿领取。原版还有更完整的遭遇四级难度、动态敌阵和专家系统，当前并不冒充全部已完成。
- 原版复活扣行动值、最低通关进度的精确阈值尚未完全实现；当前战斗仍在前台全灭时结束，结算按剩余敌方生命计算完成度和扣血。奖励节点用较高行动上限及弱敌模拟，不声称是真正无限行动值。

## 验证

自动规则测试覆盖 23 节点完整推进、12 节点超频、三处补给无战斗、遭遇难度影响战斗数值、首领前额外补给、额外投资、第三位面遭遇替换、最终存活判定、旧档兼容、每次动作后的合法性和逐节点重载。

另以真实 `act()` 操作（无改金币、星级、生命、掉落或战斗结果）跑过标准种子 123、789 和超频种子 123：领取晶矿、开箱、买角色、买经验、刷新、穿戴、部署、选补给/遭遇均实际执行。标准为 20 场战斗 + 3 个补给，超频为 9 场战斗 + 3 个补给；均达到最后整局结算。该规则脚本验证不替代浏览器实际操作；页面端另行从开局实玩到结算检查。
