# 晶矿、武装箱与成长奖励流程

本轮核对日期：2026-11-14。目标仍为 4.7 之前的「零和博弈」。

## 可核对的依据

- [原版新手任务文本](https://wiki.biligame.com/sr/货币战争（任务）)包含“开启全部晶矿”“打开武装箱”“合成进阶装备”三个连续操作，支持先掉落、再领取、再开箱的顺序。
- [首发社区教学](https://www.miyoushe.com/sr/article/70366575)记录白色、蓝色、金色战利品；用户提供的实机图显示更大的彩色晶矿。[旧赛季实机](https://www.bilibili.com/video/BV18wKe6hEJh/)中可核对棱彩晶矿。
- [公开装备表](https://wiki.biligame.com/sr/装备一览)保留简易、进阶、特权武装箱、员工投影仪、完美员工投影仪、冶金炉、特权卡、财富宝钻及星徽资料。36 件特权装备的属性表覆盖到 `classic-privileged.js`，22 种星徽覆盖到 `classic-emblems.js`。没有将所有特权值简单乘二：被动的回合间隔、阈值、触发次数按对应条目处理。
- 武装箱取消保留由用户明确要求；未找到足够可靠的公开文字确认原版所有箱型都具有这一行为。本作明确保证取消后不消耗、不重抽。

## 当前真实执行的流程

新局不直接塞装备仓库，三件初始简易补给分别是可点击蓝色晶矿。普通补给节点掉落简易武装箱晶矿，首领胜利掉落进阶或特权武装箱晶矿。成长与祈愿奖励先生成晶矿：白色资源、蓝色基础道具、金色进阶装备、较大的棱彩特殊奖励。拾取才转入资源、角色、装备或道具仓库；含角色的晶矿在备战席满时保留整个奖励，避免局部发奖与重复金币。

武装箱的三个选项在掉落时确定并随存档保存，打开或取消均不消耗随机数。仅确认选项时消费箱子。投影仪复制目标的一星本体并保留费用形态；不会复制星级与装备。特权卡、同品级重铸、招聘券、冶金炉在实际阵容和物品上生效。星徽是占装备栏、可卸下的装备；财富宝钻持有即增加团队规模，穿戴后每三个备战节点产出金币。

自动回放、单步到末尾或跳过回放均直接切换结算页面。回看仅展示已经保存的战报，不重新计算收益。

## 没有证据的部分

本轮检索了「货币战争 REA」「星穹铁道逆向/解包逻辑」以及公开 GitHub 代码。搜索命中的 `RogueTourn` 实际是差分宇宙，并不能作为货币战争内部规则依据；找到的货币战争自动化项目也只证明界面操作流程，不能证明服务器战斗公式。本轮没有找到可核验的经典货币战争完整 REA 分析或服务器实现，因此不声称按逆向代码复原。

本作 12 关的掉落时机、补给总量和首领奖励档位仍为独立短局配置，不伪称原版掉率。原版成长阈值和可确认奖项采用资料表；未确认的随机奖池分支和数值边界见成长研究文档。
