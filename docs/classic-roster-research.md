# 经典角色与羁绊资料核对

核对日期：2026-11-13。范围是 4.7 改版前的 **零和博弈** 赛季，包含该旧赛季后续扩展；不是只含 3.7 首发角色，也不是 4.7「入画奇航」。

## 数据来源与版本隔离

- [BWIKI 角色一览（货币）](https://wiki.biligame.com/sr/角色一览（货币）)：网页有新旧两张表，仅使用「零和博弈」。
- [BWIKI 羁绊一览](https://wiki.biligame.com/sr/羁绊一览)：同样仅取旧赛季。
- MediaWiki Semantic API 按 `[[分类:货币战争角色/零和博弈]]` 与 `[[分类:货币战争羁绊/零和博弈]]` 查询名称、费用、站位、羁绊、实装版本。
- 每个人物、羁绊单页再次核对。单页同时有新旧版本时，只解析 `== 零和博弈 ==` 后的模板（标题空格允许变化），不会把页首新版本当作旧版。
- `dist/classic-roster.js` 每条记录保留 `sourceUrl`、`sourceSeason`、`sourceVersion`，数值都能回到具体来源检查。`sourceVersion` 表示该条目的实装版本，不代表冻结在这一补丁的平衡数值。
- 名称与图片 ID 对照：[Mar-7th / StarRailRes](https://github.com/Mar-7th/StarRailRes)。三月七特意使用存护形态 1001，避免与巡猎形态混淆；两种开拓者分别为 8007、8009。

获得 73 个语义页面记录，去掉银狼 LV.999 的重复 4 费条目后是 **72 个角色、33 个羁绊**。按基础费用分组：1 费 20 人、2 费 15 人、3 费 14 人、4 费 14 人、5 费 9 人。银狼 LV.999 的可变费用另存 `costVariants: [3,4,5]`，基础商店费用为 3。

## 数据和模拟的边界

`allowedZones` 是激活原版赋能的位置，不等于禁止把角色拖到其它区域。移入备战席不应该改变头像显示；备战席角色不计入上场羁绊。

`referenceStars` 中的前后台强度、治疗强度、护盾强度是原游戏的强度点数；生命和速度增幅采用小数比例，**不能当作角色攻击力、生命绝对值直接套用**。例如瓦尔特 1/2/3 星前台强度为 200/320/2000，生命增幅为 60%/108%/500%，速度增幅为 45%/60%/300%。因此不能对所有费用统一使用同一个升星乘数。1、2 费原版资料通常有 4 星列，较高费用通常为 3 星列。

`empowerments` 保存赋能名称、作用位置、功能说明和可核实的技能规则；`referenceStarStats` 保存原始星级值。`CLASSIC_TRAITS[].levels[].effects` 结构化记录每档加成；`mechanics` 记录触发条件、受益者、累积阈值等。它们是**原版参考规则**，不是“网页引擎已完整实现全部事件”的声明。实际的回合制简化与参数缩放以 `combat.js` 和页面模拟说明为准。

原资料没有提供的细节保留未知，未冒充原版数字：

- 风堇的旧版赋能只写“小伊卡额外记录全队治疗量，并造成更多伤害”，没有子技能倍率。
- 战技点抽奖没有给出精确概率；盛会之星的羁绊总页没有完整每档数值。
- 2026-11-14 更正：猫糕、狼狩、夜之半神的完整成长表位于模板后的正文，已核对并接入跨节点模块；圣杯试炼参考冻结于4.6的公开实测表。见 `classic-progression-research.md`。
- 列车撞击倍率、低档神君的基础段数不能从该羁绊页完整确定。
- 银狼 LV.999、师徒、诗篇、占卜、领航员等专用流程的实现与仍有的简化边界，现记录于 `classic-progression-research.md`。
- 部分单页存在原始疑似笔误，如记忆开拓者“20%/20%/10 点能量”。保留参考文字以便复核，不能自动把异常字面值当作可靠可执行数值。
