# 开局、经济、棋盘、职级与结算核对（网站 v6.2 – v6.4）

核对时间：2026-11-17。目标是 4.7「入画奇航」改版之前的「零和博弈」。4.7 于 2026-11-11 上线，之后发布或编辑的攻略页面大多混入了新赛季内容，本文件只采用能确认属于旧赛季的资料：带版本号的游戏内教程存档、2026 年 3 月的无解说实录，以及 3.7–4.6 的客户端数据。没有读取或声称取得原版服务器实现，也没有实际运行原游戏。

v6.0 / v6.1 的开局（4 级、16 金币、场上预置 4 名角色）没有任何资料支持，是错误的；v6.2 起新开的对局按下表执行。v6.3 又补上了超频路线、固定格子、拆装扳手、失败扣血和节点结算页；v6.4 补上职级、遭遇的最低进度、开局补给的费用、倒计时战斗和「返回备战」，并把武装箱移到备战席、按原版改了装备合成的交互和星徽、扳手图标。旧存档中进行到一半的对局保留原规则，不会被中途改写：`flow.rules` 缺省为 v6.0 / v6.1 规则，`2` 为 v6.2，`3` 为 v6.3，`4` 为 v6.4。

## 仍未核实或仍为网页适配

- 失败扣血中两部分的相加方式和取整。没有找到一段显示失败结算的旧赛季画面来核对。
- 倒计时战斗的细节：致命攻击后回复多少生命（网站 50%）、A3 起的惩罚具体多大（网站 0.5 轮）、一轮折合多少行动值（网站 100）。
- 开局补给「费用合计 6」只有两段完整样本；晶矿里具体是什么仍未确认。
- 首领、遭遇和补给节点的奖励仍是网页数值：首领掉落进阶 / 特权武装箱和 5 金币，遭遇三档奖励，补给包为（位面 + 1）费角色加简易装备。原版遭遇有四档（客户端 `GridFightBinaryNodeRule` 品质 1–4，敌人难度 +0 / +5 / +10 / +20），网站仍是三档。
- 职级中的敌人词缀、敌人星级提升、策略提升难度和狂化节点没有模拟；敌人强度按三档网页适配，不是客户端的倍率（A0 ×1.05 到 A8 ×10.8，按真实账号练度设计）。
- 聘用书没有找到原版图标，网站自绘信纸图标。武装箱返回后保留是网页行为，原版是否允许不确定。
- 出售角色时身上的装备去向。网站返还到物品栏，未见资料。
- 结算页的版式是自绘的；原版在列出明细前有一段「挑战进度」动画，网站用进度条填充动画代替。
- 除商店按钮、拖起角色、点空棋盘之外，是否还有其他收起商店的方式未见资料。Esc 收起是网页端的便利设置。
