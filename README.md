# 货币战争 · 经典回响

以《崩坏：星穹铁道》旧赛季「货币战争·零和博弈」为参考的非官方浏览器策略小游戏。选择博弈模式与投资环境，刷商店、招募和出售角色、追求升星、组合装备、选择投资策略，再用前后台阵容完成三个位面的远征。

[直接试玩](https://wudifeixue.github.io/CurrencyWarsClassic/) · [源码仓库](https://github.com/wudifeixue/CurrencyWarsClassic)

**网站 v6 加入标准博弈的 23 节点路线、超频博弈的 16 节点路线，以及实际影响开局、经济和节点的投资环境。** 当前包含 72 名经典可招募角色、33 项原版羁绊资料、44 件常规装备、36 件特权装备、22 种可穿戴星徽、57 个合成配方、59 项可选投资策略、65 项投资环境和 26 首可购买诗篇。红蓝钻、垃圾袋与财富宝钻已接入领取和合成；给角色穿戴第二件兼容材料会自动合成。另保留 5 名早期网页角色用于读取旧存档，内部共有 77 名角色；这 5 名角色不会进入新局商店。

战斗是基于速度的二维自动回合模拟。技能、治疗、护盾、持续伤害、弱点击破、追加攻击和装备被动参与逐次结算；胜负取决于实际战况，阵容估值仅供参考。它是一款有明确简化范围的独立改编，不是原游戏的完整复刻或强度计算器。

## 怎么玩

1. 新局先选择标准博弈或超频博弈及挑战职级（A0 黑铁至 A8 财富造物主，页面下方列出已生效的职级规则），再从三个投资环境中选一项。环境候选可刷新一次。确认后进入 1-1：**队伍 3 级，上场 0/3，棋盘是空的**；「开局补给」的 4 名一星角色在备战席（费用为 1 / 1 / 2 / 2 或 1 / 1 / 1 / 3），另有 3～4 金币、一件简易装备和一枚晶矿。概念股环境会把其中 2 名换成对应羁绊的角色，契约类环境的角色额外加入。需要自己把角色从备战席拖上场。
2. 点击右下角的金币面板打开商店，再点一次、点空棋盘、拖起任意角色或按 `Esc` 都会收起；1-1 之后每个节点开始时商店会自动弹出。在上方五格商店招募角色：点击卡牌放入备战席，或把卡牌直接拖到备战席、前台或后台的空位。拖动头像到空位即可部署，拖到另一名角色身上会交换两人位置；点击角色会在右上角显示详情卡，也可以用其中的移动按钮。按角色右上角的「前 / 后」赋能标记部署；放在其他区域不会禁止摆放，但不会激活对应赋能。备战席角色不参加战斗，也不计入上场羁绊。
3. 三张同星同角色自动合成为更高星级，最高三星。升星优先保留已部署角色，不相容或超出栏位的装备会退回物品栏。需要回笼资金时，可点击角色详情中的「出售角色」、拖起角色后放到左右底角出现的出售区，或悬停角色按 `E`；一星按费用返还，2 费以上的二、三星少返 1 金币，已穿戴装备退回物品栏。
4. 点击场上的白、蓝、金、棱彩晶矿领取资源、角色、装备或武装箱。武装箱和聘用书会放进备战席的一个格子（占用备战席位置，可拖到别的格子），点「开启」后从四个选项里点一张卡片即可获得；「返回」会原样保留。晶矿里有角色、武装箱或聘用书而备战席已满时无法开启。
5. 右侧是物品栏。点击一件装备会弹出装备卡，列出它的「可合成列表」（＋ 搭档 ＝ 成品），已拥有的搭档会被框出，点一下即可在物品栏里合成；也可以把一件装备直接拖到另一件上合成，或将第二件兼容材料穿戴到同一角色上自动合成。原版没有单独的装备工坊，本作已移除。即使角色已有三件装备，替换已有材料的合法合成仍可执行。通常每人最多三件，白昼装备也占用栏位；唯一装备不能重复穿戴，「随便骰子」需要三个空栏位并占用其余两栏。冲突合成不会消耗材料。装备穿上后不能直接取下：开局自带一把「精密拆装扳手」，把它拖到角色身上（或在角色详情里点扳手按钮）会一次取下该角色的全部装备，可无限次使用；持有它时再获得「拆装扳手」会改为获得 1 金币。A6 起开局改发用完即失的普通拆装扳手。出售角色时装备仍会返还。
6. 按节点选择投资策略、补给礼包或遭遇难度。选择投资策略时可以点「返回备战」先整理阵容，之后用右侧的「选择投资策略」回来；出战要等选完策略。补给选择后不用战斗；投资选择后仍须作战，奖励节点也有战斗。标准路线通常在 1-3、2-2、3-2 选择策略，在 1-5、2-3、3-3 选择补给；环境可能增加选择。打开「羁绊成长」可指定巨星与领航伙伴、分配白昼装备、接受圣杯祈愿、购买诗篇、选择启示或银狼骇入。
7. 点击「出战」观看自动战斗；回放完成或跳过后直接进入结算，再继续下一节点。每个节点打完后进入「挑战完成 / 挑战失败」结算页，依次列出挑战进度、小队生命值、获取经验、获得金币总览（基础奖励、连胜、利息）、掉落晶矿和数据统计。标准首领节点为 1-9、2-7、3-7；超频为 1-6、2-5、3-5。小队生命耗尽或最终首领结算后结束远征，展示阵容、投资效果与实际伤害统计。

前台 4 格、后台 6 格，前后台合计人数不能超过当前等级（开局 3 人，最高 10 级）；每个持有的财富宝钻额外增加 1 人；备战席为 9 格。每一格都是固定位置：角色停在你放下的那一格，空格不会被自动补齐；拖到已有角色的格子上是交换。只有财富宝钻把人数上限抬过 10 时后台才会多出格子（最多 9 格）。可见的空槽不代表当前已经拥有相同数量的上场名额。

### 经济与策略

普通刷新消耗 2 金币，免费刷新次数会优先使用，部分环境可降低价格。购买经验消耗 4 金币、获得 4 经验；每打完一个节点另得 2 经验，首领节点 10，补给节点没有。升级所需经验为 3→4 起依次 4 / 6 / 16 / 36 / 48 / 60 / 72，是旧赛季的基础等级表；A5 起改为 4 / 6 / 20 / 40 / 52 / 72 / 84，并以 80 点小队生命开局。商店五档费用概率随等级变化，显示值与实际抽取共用旧赛季概率表；环境加权也同时反映在显示和抽取中。

战斗结算金币 = 基础金币 + 连胜金币 + 利息。基础金币在 1-1 为 3、1-2 为 4，之后为 5；连胜 0～1 场时连胜金币为 1，2～4 场为 2，5 场以上为 3，失败不给，奖励节点不计入连胜。标准博弈每持有 10 金币获得 1 利息，最多 5；超频博弈不获得利息，改为更高的基础金币（1-1 为 5，其余战斗节点 10，前两个首领 15，最终首领没有）和节点经验（三个位面依次 6 / 8 / 12，首领 10 / 12 / 16，补给节点没有）。策略可以改变经济方式：例如「利息上调」提高标准局利息上限；「买断制」取消利息、改为每个新节点获得经验；「淘金客」只奖励花费金币的刷新；「武力刷新」在成功合成装备时提供免费刷新。「孪生素数」对每档费用只奖励第一次购买，读取存档不会重复领取。

锁定商店可保留下个节点的卡牌。新标准和超频模式只提供连胜奖励，不再提供旧网页的连败收入。出售价格按旧赛季数值：一星为费用，二星 3/5/8/11/14，三星 9/17/26/35/44（1～5 费）。倒计时结束前没有清空敌人会失去小队生命值：固定部分按位面为 5 / 10 / 15（首领 10 / 15 / 20），再加上「系数 10 / 15 / 20 × 未完成进度」；首领进度低于 33% 时另加 4 / 6 / 8，遭遇低于 25% 时另加 3 / 5 / 7（A3 起分别为 20 / 30 / 40 和 15 / 25 / 35）；奖励节点不扣。A0、A1 没有遭遇节点；A4 起遭遇须达到 25% 才发放节点奖励。这些数值来自旧版客户端的基础职级表，两部分如何相加和取整是按字段名推断的。敌人强度仍是模拟参数；v6.1 及更早开始的存档沿用当时的 4 级开局与经济规则，v6.2 开始的对局沿用当时的超频路线、扣血公式和免费卸装，v6.3 开始的对局沿用当时的前台全灭判负和三选一武装箱；正在进行的旧 12 关存档继续其原规则。

## 回合制战斗

战前构筑决定自动行动策略与触发条件。前台承担敌方攻击，后台依据赋能主动行动或响应事件；后台不会直接承受敌方常规攻击。速度、行动提前与延后会改变出手顺序，前台共享战技点，技能、羁绊和装备可以改变其上限与恢复方式。

不同搭配会改变实际事件。例如，桑博施加并引爆风化，卡芙卡提前引爆持续伤害；三月七在后台提供护盾，黑塔在敌人生命越过阈值时追击；「掩体生成枪」按回合为前台加盾，「蓄能帆」按经过的行动值回能，「火力风暴潮」随攻击累积强度。这些效果不是只折算成一个总战力数值。

护盾先吸收伤害，治疗按实际损失的生命恢复。匹配弱点的攻击削减敌方韧性，击破触发附加伤害与行动延后。每场战斗有倒计时：战斗与遭遇按位面 18 / 15 / 12 轮，首领 20 / 16 / 16 轮，奖励节点 99 轮。按旧版规则，角色受到致命攻击时不会倒下，而是回复部分生命（本作 50%），同时剩余倒计时减少 0.25 轮（A3 起本作取 0.5 轮）；倒计时结束前击败全部敌人则获胜。回复比例和 A3 的数值没有公开资料，是估计值。角色单场损失的生命不会带到下一场，战败另行扣除远征小队生命。

战斗回放提供暂停、单步、1× / 2× / 4× 速度与跳过功能。节点结算页可切换到完整的伤害柱状图，并回看最近一场战斗；整局结束时另有阵容总览。回放控制不会改变已经计算好的结果。伤害统计包含对护盾造成的伤害，治疗统计使用实际恢复量。

## 横版界面

界面按照玩家提供的实机截图重绘：蓝紫色竞技场、顶部悬浮商店、中央方形角色卡、底部备战席、左侧羁绊、右侧装备，以及投资选卡和黑金结算页面。采用 **1920 × 1080 的 16:9 画布**，随窗口整体缩放；桌面与横屏设备更适合操作，竖屏可使用放大功能。

v6.4 按 4.7 之前的客户端数据、新手引导脚本、教程配图和实录又改了一轮：武装箱与聘用书改为放在备战席格子里、四选一、点卡片即获得；点开装备会显示可合成列表，物品栏里可以把一件装备拖到另一件上合成，装备工坊已移除；22 种星徽、两种扳手和冶金炉改用原版图标；新增挑战职级（A0–A8）、遭遇的最低进度、开局补给的费用、倒计时战斗（不倒下、致命攻击缩短倒计时）和策略选择时的「返回备战」。依据和估计值见 [开局、经济与商店行为核对](docs/classic-opening-research.md) 的 v6.4 一节。v6.4.1 把奖励节点的掉落改回实录的规模：1-1 两白两蓝、1-2 三白两蓝的小额晶矿（免费刷新、低费角色、简易装备），不再每个奖励节点送金币晶矿和武装箱；策略界面的「返回备战」移到右上角，与原版一致。

v6.3 补上了 v6.2 留下的几项：超频博弈改为旧版的 16 节点路线和对应的金币、经验；棋盘和备战席改为固定格子；卸装改为使用拆装扳手；失败扣血改用旧版客户端的惩罚表；节点结算改为「挑战完成」页。

v6.2 按 4.7 之前的游戏内教程、实录和客户端数据重新核对了开局与经济：此前的「4 级、16 金币、场上预置 4 人」开局是错误的，现改为 3 级空棋盘加开局补给；升级经验、节点经验、结算金币、连胜和出售价格改为旧赛季数值；商店默认收起、新节点自动弹出，拖起角色或点空棋盘会收起；出售区只在拖动角色时出现；角色详情卡固定在右上角。依据和尚未核实的部分见 [开局、经济与商店行为核对](docs/classic-opening-research.md)。

v6.1 重做了操作手感：界面改为局部更新而不是整页重绘，招募时卡牌飞入备战席，升星有合并与星光特效，出售会飞向金币并跳字，刷新时卡牌依次翻入，升级有横幅提示，羁绊升档会闪光。拖动时会实时预览落点（可放置、交换、人口已满、出售价格、装备能否合成），非法落点会回弹。羁绊、装备、节点等改为统一样式的悬停提示，悬停羁绊会高亮相关角色，悬停商店卡会高亮已拥有的同名角色。同时修正了模式页难度栏压住卡片、开始按钮偏移、环境卡描述被头像遮挡、晶矿与刷新按钮重叠、开箱按钮错行、策略页提示压住刷新按钮、底部页脚压住出售区、部分按钮字号被重置为 12px 等布局问题。系统设置为减少动态效果时会跳过这些动画。

v4 修复了角色移入备战席后头像变黑，以及人口数字旁图标错位的问题。备战席头像保持正常显示，人口标记与角色前后台赋能标记分别呈现。商店可以收起，装备与羁绊使用已取得的原版图标，并保留本地备用图形。

快捷键：`D` / `R` 刷新商店，`F` 购买经验，悬停或键盘聚焦角色（或打开其详情卡）时按 `E` 出售，`Esc` 关闭详情、收起商店或取消拖动，空格出战或暂停回放，`→` 单步回放，`?` 打开玩法指南。

## 存档兼容

进度自动保存在当前浏览器的 `localStorage`。重新访问同一网址可继续；本地地址与 GitHub Pages、不同浏览器或不同设备之间不会自动同步。清除网站数据会删除进度。

网站早期版本使用的存档结构 v1 / v2 会自动迁移到结构 v3，已有金币、角色、装备、关卡、策略和战报继续保留。**没有新流程字段的旧 v1 / v2 / v3 存档仍走原 12 关路线**，不会把进行中的对局改成 23 节点。新局在结构 v3 中增加模式、环境和节点选择字段，保存后可继续对应的新路线；主动开始新局才会替换当前进度。

旧存档中的非经典角色与早期自制策略保留兼容行为，但不进入新局随机池。装备 ID 保留，名称、配方和效果更新为经典规则；原先允许的重复唯一装备或骰子栏位冲突会整理并返还仓库，不会直接丢弃物品。

迁移不会重发策略奖励或补发已结算的成长奖励。旧存档尚未完成的装备三选一会保留为固定选项的武装箱；已领取装备不变。新版本会保存未领取晶矿、箱子、成长里程碑、试炼与独立选择，重新载入不重复结算。有逐次事件的旧战报可以继续回看；最早没有回放数据的战报不能补生成历史过程。网站版本号与存档结构版本号是不同概念。

## 本地运行与测试

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 4173 --directory dist
```

打开 [http://localhost:4173](http://localhost:4173)，或使用 `npm start` 启动相同服务。页面使用 JavaScript 模块，需要通过 HTTP 服务访问。

使用 Node.js 22 或更新版本运行测试：

```sh
node --test tests/*.test.mjs
```

也可以运行 `npm test`。测试覆盖合成配方、角色身上自动合成与冲突回滚、升星与出售返还、经济策略、环境触发与奖励去重、商店概率、人口限制、存档迁移、两种模式的完整节点推进、回合战斗及界面数据。自动规则检查与浏览器实际操作是不同验证；[v6 实玩记录](docs/v6-playthrough.md) 记录了标准博弈从开局到 3-7 最终结算的完整界面操作和修复。项目没有需要 `npm install` 的运行依赖，也没有额外构建步骤；`dist/` 就是可部署的网站。

## GitHub Pages 发布

仓库 **Settings → Pages → Build and deployment → Source** 使用 **GitHub Actions**。推送到 `main` 或手动运行 `Deploy to GitHub Pages` 工作流后，先执行规则测试，通过后上传 `dist/` 并部署。工作流发布静态文件，不需要应用服务器或额外部署密钥。
