# 货币战争 · 经典回响

一个受《崩坏：星穹铁道》3.7 版本「货币战争·零和博弈」启发的非官方浏览器策略小游戏。围绕刷商店、选角色、追三星、配装备和选择投资策略，组建队伍完成一场远征。

**v3 按实机截图重做了 16:9 棋盘、悬浮商店、方形角色卡、投资选卡和黑金结算界面。** 保留真正的回合制自动战斗。 角色依照速度行动，技能、护盾、治疗、持续伤害、弱点击破和追加攻击逐次结算。胜负由战场中的生存与实际伤害决定，阵容综合估值只用于参考。

当前包含 **24 名角色、12 个关卡、阵容羁绊、装备合成、投资策略选择、战斗回放和本地自动存档**。纯 HTML、CSS 和 JavaScript，无需安装前端依赖或连接游戏账号。

[直接试玩](https://wudifeixue.github.io/CurrencyWarsClassic/) · [源码仓库](https://github.com/wudifeixue/CurrencyWarsClassic)

## 怎么玩

1. 从上方五格商店招募角色，将备战席中的角色安排到前台或后台。
2. 根据角色技能和羁绊补齐阵容，在刷新商店、追求升星、购买经验与保留利息之间取舍。
3. 三张同星同角色自动合成为更高星级，最高三星。两件简易装备可以合成一件进阶装备。
4. 点击仓库装备选择穿戴角色。每位角色最多三件，已穿戴装备可免费卸下；合成操作在装备工坊中完成。
5. 第 2、6、10 关开始前选择投资策略，其他补给关卡选择装备。部署完毕后点击「出战」。
6. 查看自动战斗与结算，再继续下一关。第 4、8、12 关为首领，击败最终首领完成远征。

商店刷新通常花费 2 金币，购买经验花费 4 金币。每持有 10 金币可获得 1 利息，通常最多 5；投资策略可能改变这些规则。锁定商店可以保留下回合的卡牌，出售角色会返还其装备。

## 回合制战斗

战斗由自动策略执行，玩家通过战前的角色、站位、装备和投资选择影响战局。回放控制用于观察过程，不会改写已经计算好的战斗结果。

| 机制 | 当前规则 |
| --- | --- |
| 行动顺序 | 使用速度和行动间隔推进；加速、减速和行动提前会改变出手频率与顺序。 |
| 战技点 | 前台共享战技点，初始 3 点、最多 5 点。普攻恢复 1 点，战技消耗 1 点；自动策略会按可用点数与角色状态选择行动。 |
| 能量 | 普攻、战技、受击与部分角色、羁绊、装备恢复能量。能量达到 100 后，在角色的下一次行动施放终结技。 |
| 前后台 | 前台最多 4 人并承担敌方攻击；后台按自身速度触发专属支援或终结技，可以造成伤害或辅助队友，不直接承受敌方攻击，也不消耗前台共享战技点。 |
| 生存 | 护盾先吸收伤害；治疗恢复实际损失的生命，不复活退场角色。前台全灭时失败。 |
| 持续伤害 | 灼烧、触电和风化在目标行动前结算；卡芙卡可以提前引爆已有持续伤害。持续伤害也会受到护盾影响。 |
| 弱点击破 | 匹配敌人弱点的攻击削减韧性；击破附加伤害、提高受伤并推迟行动。银狼的弱点植入可改变削韧条件。 |
| 追加攻击 | 由明确条件触发，例如克拉拉受击反击、黑塔首次半血追击、姬子积累击破后追击，以及景元的神君。 |
| 胜负 | 敌方全灭则胜利；前台全灭或达到行动上限仍未清除敌方则失败。阵容总分不参与胜负比较。 |

「前台全灭判败」、后台支援覆盖范围以及本作的具体行动与资源规则都是为这款小游戏设计的简化方案，不表示已逐项复刻旧版规则。

角色图鉴可查看战技、终结技与后台赋能的实际说明。例如，丹恒对减速目标的终结技更强；停云能帮助主力补充能量；桑博叠加风化，卡芙卡引爆持续伤害；克拉拉在前台承受攻击才有机会触发反击。角色放在不同位置时，效果和触发条件也不同。

羁绊与装备同时影响属性和事件。比如「星穹列车」在击破时为全队恢复能量，「星核猎手」奖励击杀者能量，「坚壁」增强护盾；「永动机」提供开场与行动能量，「破阵长刃」将直接伤害转为治疗，「幸运彗星」提高暴击率与追加攻击伤害。完整数值以当前图鉴、装备说明与战斗记录为准。

## 横版界面与战斗回放

筹备界面采用 **1920 × 1080 横版画布**，按窗口整体缩放，保持各操作区的相对位置。小屏竖向窗口会提示横屏，并提供放大操作；桌面或横屏设备更适合查看完整棋盘。

布局根据玩家提供的实机截图重绘：蓝紫色竞技场、顶部覆盖式五格商店、中央方形角色头像与卡外装备、底部备战席、左侧悬浮羁绊、右侧装备与橙色出战按钮。收起商店即可查看完整棋盘。点击角色打开配置浮层，调整站位或卸下装备；投资卡先选择再确认。战后可切换阵容总览与实际伤害柱状图。角色槽数量不等于可同时上场的人数，实际部署总人数仍受团队等级限制。

自动战斗会显示双方生命、护盾、能量、敌方韧性、状态、行动顺序与事件记录。支持：

- 暂停或继续播放。
- 单步查看下一条战斗事件。
- 切换 1×、2×、4× 回放速度。
- 跳过回放，直接查看结果。
- 在结算页回看最近一场战斗，比较各角色的伤害、治疗和护盾贡献。

伤害贡献包含对护盾造成的伤害；治疗按实际恢复量计算，护盾贡献记录实际授予的护盾量。战斗结束后，角色在单场内损失的生命不会永久带到下一场；战败另行扣除远征小队生命。

快捷键：`D` / `R` 刷新商店、`F` / `E` 购买经验、空格出战或暂停回放、`→` 单步回放、`?` 打开指南。

## 存档

进度保存在当前浏览器的 `localStorage` 中，重新打开同一网址可继续。存档不会跨浏览器、跨设备或在本地地址与 GitHub Pages 之间同步；清除网站数据会删除进度。

**v1 / v2 存档仍然兼容。** 已有阵容、经济和关卡进度可继续使用；旧版战报没有逐次行动数据，因此无法补生成新回放。更新后进行的新战斗会使用回合制规则，并保存最近一场战斗的回放。

## 本地运行

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 4173 --directory dist
```

打开 [http://localhost:4173](http://localhost:4173)。也可以使用 `npm start` 启动相同服务。页面使用 JavaScript 模块，请通过 HTTP 服务访问。

使用 Node.js 22 或更新版本运行规则测试：

```sh
node --test tests/*.test.mjs
```

或运行 `npm test`。本项目没有需要 `npm install` 的运行依赖，也没有额外构建步骤；`dist/` 就是可部署的网站。

## 与经典版的关系

本作以 3.7 首版为灵感，保留五格商店、角色三合一、前后台构筑、经济利息、装备合成和策略选择的循环。界面与机制参考：[3.7 入门介绍与操作技巧](https://www.miyoushe.com/zzz/article/70549693)、[2025-11-05 HoYoLAB 首版介绍与截图](https://www.hoyolab.com/article/42168333)、[2025-11-27 旧版实机筹备截图](https://note.com/dowaoshark/n/n8a377f6d419a)。

| 内容 | 本项目的处理 |
| --- | --- |
| 角色与卡池 | 选取 24 名角色；费用、基础属性、羁绊归属采用本项目设定。 |
| 技能 | 24 名角色的战技、终结技与后台效果参与实际战斗；技能倍率、天赋条件和后台适用范围独立设计。 |
| 羁绊 | 使用自定义门槛、属性加成和事件触发效果，包含为简化构筑而设计的组合。 |
| 装备与策略 | 保留简易装备合成、策略三选一；数值、部分名称、配方与触发效果为自制。 |
| 战斗 | 使用二维界面和基于速度的自动回合模拟，不包含 3D 战斗，也不完整复制原游戏战斗公式或技能系统。 |
| 关卡 | 压缩成 12 关的独立单局，不照搬原版节点流程与难度曲线。 |
| 角色养成 | 所有玩家使用统一基础数据，不读取游戏内星魂、遗器或光锥。 |

这是寻找经典选卡与阵容搭配乐趣的独立改编作品，不能用于预测原版角色或阵容强度。

## GitHub Pages

在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。推送到 `main` 或手动运行 `Deploy to GitHub Pages` 工作流后，会先执行规则测试，测试成功才上传 `dist/` 并部署。工作流仅发布静态文件，不需要服务器或额外密钥。

部署配置参考 GitHub 官方的 [自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 项目结构

```text
dist/                       网站文件，可直接静态托管
  index.html                页面入口
  app.js                    招募、阵容、装备、存档与回放控制
  styles.css                通用界面与工具页样式
  reference.css             根据实机截图重绘的 16:9 备战场景
  reference-screens.js/css   投资选择与战后结算页面
  data.js                   角色、羁绊、装备和策略数据
  engine.js                 经济、升星、回合推进与远征结算
  combat.js                 速度行动、技能、状态与战斗事件模拟
  battle-ui.js              战斗回放与贡献统计界面
  assets/characters/        角色半身图片
  assets/portraits/         方形角色头像
  assets/equipment/        自绘装备 SVG
  assets/traits/           自绘羁绊图标
  assets/ui/               场景背景与金币图标
tests/                      Node.js 规则测试
.github/workflows/pages.yml 测试与 Pages 部署
```
